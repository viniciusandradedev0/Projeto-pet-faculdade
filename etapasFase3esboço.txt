# CONTEXTO — o que o modelo atual está raso
#
# Animal hoje tem apenas: Slug, Nome, Especie, Idade, IdadeMeses, Imagem, LinkDetalhes.
# Falta o que efetivamente importa para alguém adotar:
#   - Sexo                        → filtro óbvio sempre usado
#   - Porte (pequeno/médio/grande) → crucial para quem mora em apartamento
#   - Castrado / Vacinado         → pessoas filtram por isso explicitamente
#   - Cidade / Estado             → sem isso o hub é genérico, não regional
#   - Descrição / personalidade   → é o que "vende" o animal
#   - Galeria de fotos (3-5)      → uma foto só é decepcionante
#   - DataEntrada                 → "espera há 2 anos" toca emocionalmente
#
# Pedido hoje tem só: AnimalId, UsuarioId, Telefone, Mensagem, DataPedido, Status (texto livre).
# Falta:
#   - Status real em workflow     → hoje todo pedido fica "pendente" para sempre
#   - Histórico de mudanças       → adotante quer saber em que pé está
#   - Resposta da ONG             → comunicação básica
#   (estes três estão cobertos na Etapa 20)
